# Sprint 3 - User Stories
 
## User Stories

### Visualizar painel de custos

**Como** gestor do sistema,  
**quero** visualizar um painel de custos,  
**para** acompanhar de forma centralizada os valores das viagens.

**Critérios de aceitação:**

- O sistema deve disponibilizar um painel específico para os custos.
- O painel deve permitir uma visualização organizada das informações.

---

### Atualizar custo da viagem

**Como** gestor ,  
**quero** atualizar o custo de uma viagem quando permitido,  
**para** manter o valor registrado de acordo com as informações atualizadas.

**Critérios de aceitação:**

- Somente usuários autorizados devem poder alterar o custo.
- O novo valor deve substituir o valor anteriormente registrado.
- O valor atualizado deve ser refletido nas informações da viagem e no painel de custos.

---

### Integrar custos ao fluxo de viagens

**Como** usuário do sistema,  
**quero** que o custo faça parte das informações da viagem,  
**para** consultar os dados financeiros junto às demais informações da solicitação.

**Critérios de aceitação:**

- O custo deve permanecer vinculado à viagem durante seu fluxo.
