# Documentação do Projeto

Esta pasta concentra os documentos acadêmicos do **Sistema de Gestão de Viagens (SGV)**. O objetivo é manter a relação entre a especificação, o Jira, os artefatos de análise e o código-fonte clara e verificável.

## Índice

| Documento | Finalidade |
|---|---|
| [planejamento.md](planejamento.md) | Product Backlog, cronograma acadêmico de Sprints e escopo conhecido da Release R1. |
| [requisitos.md](requisitos.md) | Problema, objetivo, requisitos funcionais, regras de negócio, requisitos técnicos e matriz de rastreabilidade. |
| [entregaveis.md](entregaveis.md) | Artefatos esperados pela disciplina e critérios para considerá-los entregues. |
| [fluxo-git.md](fluxo-git.md) | Estratégia de branches, commits, pull requests, releases e vínculo com o Jira. |
| [sprint-0/README.md](sprint-0/README.md) | Objetivo, entregas e evidências da Sprint 0. |

## Fontes de verdade

| Informação | Fonte principal |
|---|---|
| Especificação e requisitos | [requisitos.md](requisitos.md), baseado no enunciado fornecido para o SGV. |
| Estado operacional do trabalho | [Projeto ES2 no Jira](https://gabrielhochmann.atlassian.net/jira/software/projects/ES2/boards/1/backlog). |
| Código, documentação revisada e histórico de contribuição | Este repositório GitHub. |

> Um documento não substitui uma evidência técnica. Quando uma issue for concluída, o Jira deve apontar para o arquivo, commit, pull request, teste ou checklist que comprove a entrega.
